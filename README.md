# 🏡 Sistema de Alquiler de Propiedades tipo Airbnb en Java

Aplicación desarrollada en Java que simula una plataforma de alquiler de propiedades, permitiendo a los usuarios publicar, buscar y reservar alojamientos.

## 🚀 Funcionalidades
- Registro de usuarios
- Publicación de propiedades
- Visualización de propiedades disponibles
- Reserva de alojamientos
- Gestión de disponibilidad

## 🧠 Lógica implementada
El sistema está diseñado utilizando programación orientada a objetos, donde se modelan entidades como usuarios, propiedades y reservas.

Se implementa la gestión de relaciones entre usuarios y propiedades, permitiendo controlar la disponibilidad y el proceso de alquiler.

## 🛠️ Tecnologías
- Java
- Programación Orientada a Objetos (POO)
- Estructuras de datos (Listas / colecciones)

## 📂 Estructura del proyecto
- Clase `Usuario`
- Clase `Propiedad`
- Clase `Reserva`
- Menú interactivo en consola para gestión del sistema

## 🎯 Objetivo del proyecto
Simular el funcionamiento básico de una plataforma de alquiler de alojamientos, aplicando conceptos de modelado de datos y lógica de negocio.

## 📈 Posibles mejoras
- Implementación de interfaz gráfica
- Conexión a base de datos
- Sistema de calificaciones y reseñas
- Autenticación más robusta
